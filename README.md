# Блок 50 — облегчённая версия для GitHub Pages

Это оптимизированная версия модели для более плавного просмотра в браузере.

## Что улучшено

- исходная модель: 20 843 объекта, ~8,44 млн треугольников, 263 МБ GLB
- облегчённая модель: 46 объектов, ~2,62 млн треугольников, 46 МБ GLB
- gzip для веба: ~17,2 МБ

## Загрузка в GitHub

1. Распакуйте ZIP на компьютер.
2. В репозитории GitHub откройте **Add file → Upload files**.
3. Загрузите **все файлы из этой папки сразу**: `index.html`, `manifest.json`, `.nojekyll`, `README.md`, `model.glb.gz.part01`.
4. Нажмите **Commit changes**.
5. В **Settings → Pages** выберите **Deploy from a branch → main → /(root)**.
